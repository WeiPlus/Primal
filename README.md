## The English
### Features
 - Minimal progress bar
   - For Example : <thrist ████████░░>
 - Lightweight and easy to install and setup
 - A Datapack,No mod loader required

### Requirements
 1. Java 25
 2. Minecraft 26.3(Release only | Runs on vanilla Minecraft — no mod loader required.)

### Installation
 1. Create Your World;
 2. Download The Datapack File `.zip` to `saves/your-world-name/datapacks/`
 3. Into Your World
 4. Run `/reload` in your world

## 中文
### 功能特色
 - 极简的口渴进度条：
   - 例如 : <thrist ████████░░>
 - 轻量，安装、配置简单
 - 一个数据包，不需要加载器

### 前置要求
 1. Java 25
 2. Minecraft 26.3(仅正式版 | 原版即可，不需要模组加载器)

### 安装方法
 1. 创建世界
 2. 下载数据包文件`.zip`，并且放入`saves/你的存档名/datapacks`目录下
 3. 进入游戏
 4. 在游戏内执行`/reload`
